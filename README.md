# 📚 SwiftReads Bookstore

**SwiftReads** is a responsive online bookstore built with **Bootstrap 5**, featuring a clean and flexible layout that works seamlessly on desktops, tablets, and mobile devices.

---

## 🔹 About the Project

SwiftReads was designed to **practice and demonstrate responsive web design** skills using Bootstrap 5. The interface is user-friendly, adaptable, and visually appealing, highlighting the essentials of an online bookstore:  
- Book listings with titles, authors, and brief descriptions  
- Clean and structured layout  
- Fully responsive across different devices  

---

## 💻 Tech Stack

- **HTML5** – Semantic structure and content  
- **CSS3** – Styling and layout  
- **Bootstrap 5** – Responsive grid, components, and utilities
